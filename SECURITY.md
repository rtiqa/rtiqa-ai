# Security Policy

## Supported Versions

We issue security updates for the latest released versions of RTIQA.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The RTIQA core team takes security seriously. If you discover a security vulnerability, please follow these guidelines:

1. **Do NOT open a public issue** on GitHub.
2. Email your detailed findings directly to **irtiqahq@gmail.com**.
3. Include the following details in your report:
   - Type of vulnerability / potential exploit vector.
   - Step-by-step instructions or proof-of-concept script to reproduce.
   - Affected Android versions, API levels, or modular components.
   - Any potential mitigation or patch ideas.

## Response Timelines

- **Initial Acknowledgement**: Within 24-48 hours.
- **Triage & Risk Assessment**: Within 5 business days.
- **Fix & Patch Advisory**: Dependent on complexity, targeting < 14 business days.

We sincerely thank you for helping keep RTIQA and its users safe.
